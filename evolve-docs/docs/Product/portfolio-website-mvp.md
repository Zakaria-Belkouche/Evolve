# Portfolio Website MVP

**Status:** Draft

## Purpose

Create a simple static portfolio website that introduces Zakaria, provides
professional links, and highlights a small selection of projects. The MVP should
be quick to understand and easy to maintain while Evolve's portfolio grows.

## Intended Audience

Visitors to the portfolio, including people interested in Zakaria's work,
experience, and projects.

## MVP Scope

![Portfolio MVP](../../images/Portfolio-MVP.jpeg)

The website will be a static page with the following content:

- **Identity and links:** name, CV link, LinkedIn profile, and GitHub profile.
- **Role or headline:** a concise professional headline.
- **Projects:** a small selection of featured projects. Initially, each project
  links to its GitHub repository; project pages on the portfolio are future
  work.
- **About:** a short introduction or personal story.
- **Featured image:** a visual related to growth and comfort zones, or a
  suitable LinkedIn banner image.

The rough layout is a compact header at the top, followed by projects and the
about section side by side on wider screens, with a featured image below. The
layout should adapt to narrow screens without losing any content or links.

## Out of Scope for the MVP

- Separate portfolio pages for individual projects.
- A backend, database, user accounts, or content management system.
- Dynamic features that are not needed to present the portfolio content.

## Done When

- [ ] A static portfolio page presents the identity, professional links,
      headline, featured projects, About content, and chosen image.
- [ ] Each featured project links to its GitHub repository.
- [ ] The content and layout work on both narrow and wide screens.
- [ ] All text and links are readable, usable, and accessible.
- [ ] The page can be deployed as a static website without a backend service.
